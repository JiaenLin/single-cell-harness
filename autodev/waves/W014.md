# W014 (QC): scQC's environments pinned and built from `main` on a fresh prefix

**Registered** 2026-11-09 by the coordinator, before any number. **Gaps** GAP-107 (scQC's part), GAP-018,
GAP-C05, GAP-C31. **Goals** A1.3, G1, A3.1. **Repository** scQC, base `main` = `0a9d2ce`, branch
`autodev/W014-qc-env`.

## The change
- **GAP-018** The denoiser environment pins torch and numpy at the versions SAMBO's working
  `env/cellbender` holds: torch 2.5.1 and numpy 1.26.4 per ADR-0027's Q9 finding. Any other version is
  refused. The R doublet stack pins scDblFinder and its Bioconductor release at the versions
  `env/rdoublet` holds.
- **GAP-C05** pyarrow joins the core lock, so the repository's own installer builds an environment its
  suite passes in.
- **GAP-C31** `conf/env/build_reference.sh` requires SPECIES, ASSEMBLY and ENSEMBL_RELEASE, with no
  default; the error names all three.
- **GAP-107** A PBS job builds the core and rdoublet environments, and the cellbender one, from `main`
  on a fresh prefix through scQC's own installer, then runs the selftest. The coordinator submits it.

## Acceptance check
- Tests fail on `0a9d2ce`: an installer refusal of an unpinned torch, and build_reference refusing without
  its three values. The suite and the leak guard are green.

## Prediction
1. The fresh-prefix build succeeds, and the installed versions equal the lock's.
2. The selftest on the fresh core environment gives 42 passed, 0 failed, 1 skipped.
3. SAMBO stage 1 on the fresh environments equals PBS 782673's tables, run on the same scQC code. The pins
   are chosen to equal the environments that produced it; any difference in doublet calls is a finding.
