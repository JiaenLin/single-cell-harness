## The change, in this order
1. **C41 (H3).** `agree` never compares measured resources (cores, CPU, wall time, RSS, the cost and
   memory models) between shapes. They are measurements, not outputs: they are reported, never
   judged. The baseline tier passes a fixture run that correctly refused when the fixture expects that
   refusal. File sizes are not a fingerprint of content.
2. **C44 (H6).** `jobs/dev_suite.pbs` runs every maker-layout plugin of scProfile, not
   `--name abundance` only. Baselines are recorded on the cluster (W012's job 29 shows how).
3. **C42 (H4).** `plan --migrate` never defaults an entry's axis. It derives pooled or per-unit from the
   plugin, or asks.
4. **C39 (H1).** The python extractor sees class methods and submodules: a package shaped like
   pydeseq2, with plotting methods on a class and in a submodule.
5. **C40 (H2).** The layout budget charges the host's own panels to the host, once, and not to every
   plugin. A pooled plugin gets its own budget. `host_panels` is not demanded equal to a list.
6. **C43 (H5).** `sch dev edit` wraps inserted keys like the surrounding file.
