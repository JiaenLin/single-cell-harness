# W024 (HARN): the leak guard reads every file, with lists generated from each cohort's records

**Registered** 2026-11-09 by the coordinator, before any code or number. **Gaps** GAP-008, GAP-C46,
GAP-101, GAP-110, GAP-C38 (the ladder's part). **Goals** A3.1, A3.3, A2.2, HARN.2. **Repository**
single-cell-harness (`sch conform`, `sch dev`), base `main`, branch `autodev/W024-leak-guard`.

**Why now.** Rule 1's "no cohort string in a tool" is graded by one instrument, `sch conform`'s S1. Today
S1:
- never reads .ts/.tsx/.mjs/.js/.html/.sh files: it reads only TEXT_EXT, so Studio, Lab and the Service are
  "clean" on their READMEs alone (GAP-C46);
- passes when a named term file does not exist (GAP-101);
- reads lists that hold no factor levels, no first-cohort counts and no bare job ids (GAP-008). W011's
  verifier found 10 leaks, then 59 with the builder's list, all invisible to SAMBO's 22 terms;
- cannot pass on the harness itself with the cohort lists, and the commit gate runs it without them
  (GAP-110).

## The change
1. **C46.** S1 reads every tracked text file by content, not by extension; binary files are skipped by
   content sniffing. There is a test with a listed term in a .ts and a .sh file.
2. **101.** Any named list that is missing, or that yields 0 terms, is an error, whether one list or several
   are named.
3. **008.** `sch conform terms build <cohort>` GENERATES a cohort's list from its records: the design
   sheet's factor levels and sample names, and the counts and percentages in its RUNLOGs, DECISIONS and
   PROMOTED files (comma-grouped, plain 2-6 digit counts beside a measurement word, "N of M", margins),
   plus a hand-kept stems file. It writes to scratch and never edits a cohort's docs.
   - **Per-tool scoping:** a declared allow-list per repository, for content a tool legitimately holds,
     such as scAnno's reference trees naming a cell type. Each entry carries its reason.
   - **False positives:** the builder runs the generated SAMBO and C46 lists over all eight repositories
     and reports every hit, each classed as leak or false positive.
4. **110.** The harness's record paths (GOALS.md, autodev/, docs/adr/, docs/blind/, docs/postmortem/) are
   exempt from S1 by declaration. The pre-commit hook reads the cohort lists from an untracked local file
   when present.
5. **C38 (ladder).** The dev ladder reads `STATUS*.json` (scAnno writes `STATUS.<cmd>.json`).
