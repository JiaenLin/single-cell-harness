## The change
- **GAP-P19, a Run card.** Studio shows the run that produced an object, from the bundle's `meta.run`, as Lab's W017
  writes it (`{searched, records[{path, record}], leftOut, notes}`; Lab branch `autodev/W017-lab-integrity` @
  `d5b0244`):
  - each record's tool, version or commit, stage and run key, as recorded, never inferred;
  - records named but not copied (over budget) are shown as named, with their size;
  - with no `run`, the card says the object carries no run record.
- **GAP-C52, Studio's part.** Studio's pseudobulk header parser (bundle.ts:332, collection-source.ts:710) splits on
  `||`. Since W017, a split sample id can hold `|` (`sample|condition`, `#2`), so a level that is empty or holds `|`
  orphans that sample's pseudobulk columns. Parse so that no id W017 can write is misread (for example from the right,
  or by the bundle's own declared delimiter), with a cross-repository test on W017's outputs.
