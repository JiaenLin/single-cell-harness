## The change
1. **C63 (sch/dev).** A declared `fixture.execution_record` glob may match JSON leaves only. A match on a CSV column is a
   declaration error that fails `agree` and the baseline. The key part of each glob must begin with a literal segment.
   There are tests for `["*"]`, `*.csv::*` and a result column.
2. **C57 (kernel).** The pin is re-resolved. `changed()` also reports when the resolved file set differs from the pin's
   (a re-pointed `latest -> v2` symlink), naming the file.
3. **C58 (dataset).** A missing pin is never silently re-created when events.jsonl records `observations/pinned`.
4. **C59 (executor).** qsub has a timeout, and a reconcile step (qstat by job name) runs before any resubmission, so a
   timed-out qsub that did queue the job is never doubled.
5. **C60 (docs and pin).** A hard link's ctime change is documented as a refusal reason with its remedy. The chmod
   remedy for a part made writable after init says that a new init is needed. The docs' overstatements are corrected:
   "nothing re-baselines", "each file's digest", and "re-checked before anything is read". The pin is checked before
   `Stack()` reads parts.
