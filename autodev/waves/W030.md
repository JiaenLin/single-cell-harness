The change, the four protected files untouched (request.ts, scan.ts, types.ts, test-scan.mjs):
1. **GAP-C55, `scReference.ts`.** `pdx` is matched as a whole word, so `Pdx1-Cre` is a strain designation. The
   `h` + gene-symbol mark stops meaning "humanized": a human gene or promoter carried by an organism leaves it
   that organism (`hGFAP-Cre mice`, `K18-hACE2 mice` are mouse; `Homo sapiens hTERT-RPE1` is human). Only the
   humanized marks (`hu-`, `Hu-`, `huX`) and the mixture words (human, xenograft, graft, chimera, hybrid, PDX,
   ...) make a text a mixture. **Decision (C, internal, reversible; decided by GAP-C55's registered rule):** a
   humanized host typed without a mixture word (`NSG-hIL15 mice`) is read as mouse and is blocked over a human
   build, as `NSG-SGM3 mice` already is at `997d132`; `humanized NSG-hIL15 mice` or `huNSG mice` stay the
   customer's words. W015's check that kept `Mus musculus NSG-hIL15` unchecked changes with it (named in the
   commit). The question-5 refusal of a typed species says how to declare a mixture.
2. **GAP-P05 / B1-059, new modules.** `localFiles.ts`: the file handles behind a pick or a drop, kept beside
   the name list that `scan.ts` still builds (the FileList for a pick; for a drop, the top entries, resolved
   path by path with `getFile` only when a value is read). `h5lite.ts`: a read-only HDF5 reader that reads by
   `Blob.slice`: superblock 0-3, object headers 1-2, symbol-table and compact groups, compact attributes, fixed
   and variable-length strings, integers, contiguous/compact/chunked data (B-tree v1; v4 single chunk and
   fixed array), deflate (`DecompressionStream`), shuffle, fletcher32; anything else is a stated refusal, never
   a guess. `scContents.ts`: per library, the called-cell count = the non-empty lines of
   `filtered_feature_bc_matrix/barcodes.tsv(.gz)` (CeleScope `outs/filtered/`), else the filtered `.h5`'s
   barcode count (its dataspace: no data read); the chemistry = the `.h5`'s `chemistry_description`; the
   genome(s) = the distinct values of `/matrix/features/genome` (Cell Ranger 2's layout: its genome groups).
   The count matrices are never read. A folder and an `.h5` that disagree give no count, with the reason.
3. **Pre-filled, marked detected.** Chemistry (question 3) and reference (question 5) are pre-filled only when
   every library records the same value; the `.h5`'s genome wins over a path token that contradicts it, and a
   path token that names it more fully (`GRCh38-2024-A` over `GRCh38`) is kept. `answered_by` says `detected`
   until touched. The cell counts are shown per library (steps A, G, T) and written per library in the request
   as a `detected` block (cells, chemistry, genomes, and the file each came from), only for libraries the
   browser read, so W009's and W015's single-cell goldens stay byte-identical; a new golden covers the block.
   Nothing new reaches the samplesheet (scQC reads any extra column as a factor). **Not built (decided, C):** a
   per-library doublet rate. The chemistry's multiplet rate is a stated value per cohort (C46 D5 is the PI's),
   so `derive` stays as it is, with its inputs now in the request for GAP-P06's intake.
4. **Wiring.** `StepFiles.tsx` and `ScStepFiles.tsx` capture the source at intake; `App.tsx` passes it to

   stated; the UI's "only names and sizes are read" lines change with it. `.gitignore` keeps `*.h5` and
