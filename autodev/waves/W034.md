### 1. The adapter `plugins/single-cell/int@scintegrate/` (plugin.yml directory, as anno@scanno)
- `class: method`, `layer: stack`, `reversible: true`, `state_version: 1` (= scIntegrate's STATE_VERSION, checked by
  `describe` before any compute), `assays: [scrna, snrna]` (what scIntegrate accepts), `wraps` scIntegrate 0.5.0 (no DOI
  declared, none invented), `needs: [observations/raw]`, `provides: embedding/*, graph/*, column/*, table/*, object/*`,
  `sees: []`, a companion.
- **Parameters.** `scintegrate` = the checkout holding the `scintegrate` package (verbatim, required, no default); `integrate`
  = an object of `scintegrate integrate`'s own flags by its names (`-` written `_`), required. Written in scIntegrate's
  parser order (b148030): a list on an append flag (`label_sentinel`, `bio_factor`) repeats it; `true` writes a bare flag
  and only on the two store_true flags (`coarse_from_path`, `no_fast_leiden`); false/null leaves a flag out (scIntegrate's
  default); no value may begin with `-` (W026 D1's lesson); an unknown flag (including the removed `lisi_subsample`), an
  unknown parameter or an owned flag is refused by name before any scIntegrate process.
- **Owned (the kernel's or the stack's):** `h5ad` (the stack's one part, the path the manifest names, in place), `out`
  (`<out_dir>/scintegrate`, the run), `assay` and `species` (the stack's declaration, `--context`). Species comes from the
  context too, by ADR-0027's "declared once" and scIntegrate's own axes.py ("the vocabulary the harness declares axes in
  (`sch init --context species=...`)"); scIntegrate requires it, so an undeclared one is refused before any process.
  Decided, not asked (a tier-IV design).
- **Rule 2.** No declared assay: refused before any scIntegrate process. The value is passed verbatim as `--assay`; one
  that scIntegrate's `describe` does not list under `axes.assay.accepted` is refused after `describe`, naming both.
- **The calls, in order:** `[python, -m, scintegrate.cli, describe]`, `... doctor` (a record, as jobs 21 and 30b run it),
  `... integrate <flags>`; `python` = the stack's interpreter for this plugin; scIntegrate's process gets
  `PYTHONPATH=<checkout>` exactly (alone: `PYTHONPATH="$TOOL"`), cwd = the run. Logs in `<run>/logs/`, outside every
  directory scIntegrate's STATUS lists as products.
- **The stage record is scIntegrate's own, adopted:** `STATUS.json` must name this call's argv; `ok` + `SEALED.txt` + exit 0
  and no `RUNNING.txt` go on; `refused` (exit 2) refuses the mount with scIntegrate's reason and fix; anything else is a death
  quoting the headline. The object is the one `objects/*.h5ad` STATUS lists (no default name restated).
- **The layer = exactly what scIntegrate changed**, read with h5py from the object against the part, by identity:
  obs columns added or rewritten (`columns/*.csv`); obsm keys added or rewritten (`embeddings/<key>.npy` + `barcodes.txt`,
  the profile's binding); obsp keys added or rewritten (`graphs/<key>.npz`, CSR, + `barcodes.txt`). An entry the part
  carries with equal values is the observation's own and not in the layer (SAMBO: X_pca is copied; every obs column the
  object keeps is the joint object's own). What the object dropped (its obs slim, scAnno's graph) is recorded, never removed
  from the view. An encoding the reader does not know is an error naming it, never skipped.
- **Refused before any compute:** a mask beneath this mount; a stack of more than one part; a part file that is not an .h5ad.
- **Companion:** the layer removes nothing; every column, embedding and graph covers every observation the stack holds.

### 2. One kernel change: the view's digest covers embedding and graph contributions
`View.digest()` covers kept ids, masks and columns only, so a mount contributing embeddings and graphs (SAMBO's stage 3:
no obs column changes) leaves the digest unchanged: MOUNTED is invisible and E4 tests nothing. The digest gains, only when
such contributions exist, each one's capability and content digest (the file and its identity file). A stack without them
keeps its digest byte for byte (no shipped plugin contributes either today). A test fails on main.
