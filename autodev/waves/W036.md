### 1. The adapter `plugins/single-cell/prof@scprofile/` (as int@scintegrate)
- `class: method`, `layer: stack`, `reversible: true`, `state_version: 1` (= scProfile's host STATE_VERSION, checked
  against its STATUS.json and report.json after the run: there is no describe to read before), `assays: [scrna, snrna]`,
  `wraps` scProfile 0.1.0, `needs: [observations/raw]`, `provides: table/*, object/*, column/*, embedding/*`,
  `sees: [design]` (it reads the stack's design sheet), a companion.
- **Parameters:** `scprofile` (the checkout, verbatim, required); `run` (an object of `scprofile run`'s own flags by
  scProfile's names, `-` written `_`, required): parser order at 6f970e5; append flags (`control`, `covariate`, `factor`)
  repeat; bare flags (`no_cache`, `resume`, `force_all`, `all`, `no_validate`, `force`) take true/false/null only; no
  value begins with `-`; unknown flags/parameters refused by name before any process. `kernel` is scProfile's: the
  adapter names no plugin and drops none; what scProfile's own plan skips is recorded with its reason, never hidden.
- **Owned (the kernel's or the stack's):** `h5ad` (the one part, in place), `out` (`<out_dir>/scprofile`), `design` (the
  stack's `sch init --design`, in place; none declared, none passed: scProfile's plan then says what it cannot run),
  `assay` (the stack's `--context assay=`; rule 2), `organism` (the stack's `--context organism=`, verbatim; undeclared,
  absent, and scProfile infers it and records how, its documented behaviour, not an adapter default).
- **Rule 2:** no declared assay refuses before any scProfile process. The family's two words are written in scProfile's
  words for them (`scrna` -> `cell`, `snrna` -> `nucleus`, scProfile's own equivalence): passed verbatim, `snrna` would
  silently switch off every nucleus caveat. Any other word is refused naming both vocabularies. Decided (C), not asked:
  internal, reversible, and the rule decides it (no silent assay).
- **Calls:** `[python, -m, scprofile.cli, doctor (--prefix P) (--references R)]` (a record, the values the run is given;
  exit recorded, not fatal, as the stage's job), then `... run <flags>`; scProfile's process gets `PYTHONPATH=<checkout>`
  exactly, cwd = the run; logs in `<run>/logs/` (not one of scProfile's own trees, so never one of its products).
- **The record adopted:** STATUS.json naming this call's argv and the declared checkout's cli.py; `ok` + SEALED.txt +
  exit 0 + no RUNNING.txt goes on; `refused` + exit 2 refuses the mount with scProfile's reason and fix; anything else is
  a death quoting the headline; a state_version other than 1 refuses the mount.
- **The layer:** every `.csv` table scProfile's STATUS lists under `kernels/<k>/tables/` or `tables/`, referenced where it
  lies; the object report.json names, referenced; and exactly what report.json's `merged` names: obs columns
  (`columns/*.csv`) and obsm embeddings (`embeddings/*.npy` + `barcodes.txt`), read from the object by identity
  (`<part>|<obs name>`, int@scintegrate's reader, copied: a plugin borrows nothing from a neighbour). A merged layer
  (matrix) is named in the answer and a caveat, not carried (open item). DE and abundance merge nothing.
- **Refused before any compute:** a mask beneath; more than one part; a part that is not an .h5ad; a design file that
  does not exist.

### 2. No kernel change

view's D6 check. The mount is seen by its contributions (the stack lists them) and the kernel's E4 still runs.
