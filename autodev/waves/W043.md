# W043 (QC): a failed removal audit stops the run

**Registered** 2026-11-11 by the coordinator, before any code or number. ROUTE item R13, the wrong-result part. **Gaps**
GAP-119. **Goals** QC.1, A2.1. **Repository** github.com/JiaenLin/scQC, branch `autodev/W043-audit-stops`, from `main`
(`46ffe90`, W020 merged 2026-11-11).

**Why.** The audit (pass 0004) found that step 7's removal audit cannot stop a run: `audit_removal.verdict()` reduces
its findings to FAIL, REVIEW or ok, `pipeline.gate` stops only on REFUSE, and `audit_removal.enforce()` has no caller.
So a FAIL (for example "no uncalled droplet reaches the deliverable", or "keep and removed are complementary") is recorded
and the matrix is written anyway, while docs/WORKFLOW.md says the caller stops. A deliverable can be written past a failed
check: a wrong result in a promoted output's path.

## The change
1. First confirm the finding on the code at `46ffe90` and with a synthetic removal table whose audit FAILs. If it is not
   as the audit says, stop and report what is true.
2. Step 7 stops on a FAIL before any matrix is written, in the way scQC's other gates stop (a refusal a user can read,
   and, where scQC's own escape mechanism allows one, accept by name with a reason; W020 built that for refusals). A test
   that fails on `46ffe90`. docs/WORKFLOW.md made true.
3. **What this does to the promoted runs.** Read both cohorts' promoted stage-1 records (their removal audits' verdicts
   are in the run records; the first cohort's stage folder is the model). If every promoted audit was ok, the fix changes
   no promoted output and the prediction says so: a reproduction job, modelled on the newest stage-1 reproduction there,
   predicts IDENTICAL. If a promoted run carried a FAIL, say which finding and what the fixed scQC would do; that run's
   standing is then a question the coordinator takes to the PI, not something this wave decides.
4. The job: prediction in the header before any run, the submit recipe between `# SUBMIT-BEGIN` and `# SUBMIT-END`, a final
   `GATE:` line. Not submitted by the builder.
