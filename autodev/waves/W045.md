# W045 (HARN): one published object becomes the parts the stages read

**Registered** 2026-11-11 by the coordinator, before any code or number. ROUTE item R43. **Gaps** GAP-C90. **Goals** A3.4,
A6.3, A1.1. **Repository** github.com/JiaenLin/single-cell-harness, branch `autodev/W045-object-intake`, stacked on
`autodev/W042-driver-cluster` @ `4e10656` (the driver, both runs; a verifier is on it).

**Why.** A cohort can arrive as one object holding every library, as public atlases do. The tools refuse it at three points
(measured from the code by W031's builder): `qc@scqc` refuses a single file; scQC never reads a `.raw` counts slot and
refuses a normalized `X`; scQC matches the mitochondrial prefix on `var_names`, which in such an object are stable gene
ids, with the symbols in a column. The scale cohort (A3.4) is such an object, and its stage 1 cannot be written until
this exists. A1.1 forbids a script written for one cohort, so this is a general step of the harness.

## What the scale cohort's inventory measured (PBS 789168, the object before any QC; the tables are in that cohort's
## `stages/00_data/inventory/` on the workstation)
1,263,676 cells x 30,172 genes; integer counts in `raw/X` (1,000,691,133 stored values), `X` not counts; gene index is
stable ids, symbols in `raw/var.feature_name` with 10 duplicate symbols; 88 libraries, each a pool of donors, and
libraries hold BOTH arms (the first rows: 16 donors, 2 arms in one library); 261 donors, none in two arms; 274 samples. So
the unit scQC works on (the library) and the unit a design sheet is keyed on (the donor or sample) are two different
columns. Reading the whole object took 177 s and 2.5 GB with a streaming reader.

## The change
1. **Declarations in the request** (the driver's schema, `sch/drive.py`): when `observations` names one object instead of
   a samplesheet, the request declares the library column, the counts slot, the gene-symbol column, and the replicate
   column (the unit the design sheet is keyed on), each by name. Nothing is guessed: a counts slot that is not integers
   is refused, a missing column is refused by name, duplicate symbols are handled by a stated rule that the record
   repeats.
2. **The step:** read-only per-library parts (`X` the counts, `var_names` the symbols, the stable ids kept in a column,
   the replicate column and the declared obs carried through) and the samplesheet manifest `qc@scqc` mounts. It must
   stream: the object does not fit in memory as a whole on a small node, and the step runs through the driver's executor
   so that its cells, wall time and peak memory are in the record like any stage's.
3. **Downstream of pooled libraries:** find, from the code, every place a stage assumes one library is one replicate or
   one arm (scQC's design checks, the harness's `differential_check`, the library key W042 added to anno, int and prof).
   Where the replicate column is needed, it is the request's second key. What cannot be fixed inside the harness is
   named, tool by tool, as a follow-up; it is not papered over here.
4. Tests: a synthetic object of that shape (pooled libraries, both arms in a library, ids as `var_names`, counts in
   `raw`), through the real CLI, that `qc@scqc` then mounts; fail on `4e10656`.
