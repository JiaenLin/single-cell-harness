# W046 (INT): scIntegrate keeps the cohort's library column, and builds from `main` on a fresh prefix

**Registered** 2026-11-11 by the coordinator, before any code or number. ROUTE item R20 (the rest of it) with GAP-C102.
**Goals** A1.3, A1.1, INT.1. **Repository** github.com/JiaenLin/scIntegrate, branch `autodev/W046-key-and-build`, stacked
on `autodev/W039-withheld-pca` @ `75ab03a` (W039: verified, its job on the cluster).

## Why
1. **GAP-C102.** scIntegrate keeps a design sheet's factors in its object but drops the sheet's KEY column
   (`cli.py:489-503`, `inputs.py:204-219`). Measured with the real tools on 2026-11-11: stage 4 is then handed the
   cohort's own library column on an object that no longer carries it, and scProfile refuses. Any cohort whose library
   column is not the first tool's own word stops at stage 4, the scale cohort among them.
2. **A1.3.** scIntegrate has never been shown to build from `main` on a fresh prefix on the cluster and pass its
   self-test (scQC, scProfile and scAnno have).

## The change
1. scIntegrate keeps the design's key column in the object it writes, under the name the cohort gave it, and says so in
   its record. A test that fails on `75ab03a`, through the real CLI. Nothing else in the object changes.
2. A fresh-prefix build job in the first cohort's `stages/03_integrate/jobs/`, modelled on scAnno's
   (`stages/02_annotate/jobs/30_scanno_env_fresh_build.pbs`, graded AS PREDICTED as PBS 789141): build the environment
   from the lock on a prefix that did not exist, run scIntegrate's self-test, and run one real integrate on the
   harness's fixture at a size that exercises every method. Before writing it, check what scAnno's wave found in its own
   lock (unpinned packages the resolver could move; an installer flag the site's conda does not take) and whether
   scIntegrate has the same.
3. The key column changes what a promoted run's object carries, so a reproduction is owed. By RULES item 14 a job over
   2 hours comes with a subset job: write `<name>.subset.pbs` (the same steps on 2 of the cohort's libraries, its own
   prediction, minutes long) and the full job, both predicting the promoted object IDENTICAL but for the one added
   column. Model: `32_w039_withheld_pca_reproduce.pbs`. Not submitted by the builder.

## Acceptance check
The tests fail on `75ab03a` and pass on the branch; the suite green with a shadowing `tests` package; `sch conform` with
both cohorts' terms and shapes shows no new hit; the build job, the subset job and the full job each read
`GATE: AS PREDICTED` when the coordinator runs them at the head that merges.

## Prediction

before code.
