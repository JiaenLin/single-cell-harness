# W048 (QC): scQC is leak-clean under the cohorts' generated lists, and the fixture's axes reach its pipeline

**Registered** 2026-11-11 by the coordinator, before any code or number. ROUTE item R13, run 2 (run 1 was W043, merged
at `de62f78`). **Gaps** GAP-C78, and scQC's part of GAP-C26 and GAP-023. **Goals** A3.1, QC.1. **Repository**

## Why
A3.1 is 0.41, under the bar of 0.5. Half of it is the leak-and-fixture half: a tool counts when it is leak-clean under
each cohort's generated term and shape lists AND the two-shape fixture's axes reach its pipeline. scAnno counts since
2026-11-11. scQC does not: under the generated lists its own text holds more than two hundred hits (GAP-C78 counted 218
on the main line), and its own guard reads the lists' `word:` and `exact:` lines as literal text, so it checked only the
carried terms.

## The change
1. **The guard first.** scQC's own leak guard reads the generated lists' syntax (`word:`, `exact:`, shapes) the way the
   harness's conform does, so that it fails today for the reason that is true. That failing guard is the test that fails
   on the base.
2. **Every hit in scQC's own files goes, its fact stays.** A cohort's sample name, count, path or run key leaves the
   tool; what the sentence said about the METHOD stays, restated without the cohort (a number that is one cohort's
   measurement goes to the cohort's record, not into the tool; ATTACKS 16). No excuse is added to any scope list, and no
   term is removed from a list. A record the tool writes (design files, history, ledgers it generates) is scanned too
   (ATTACKS 5).
3. **The fixture's axes reach the pipeline.** `sch dev check --only fixture_a` runs scQC's real CLI on the two-shape
   fixture past `describe`: the value axes (assay cell and nucleus; the design's factors) reach the steps that read
   them, and the check fails if one does not.
4. **Not in this run** (run 3, same repository, registered when this one hands back): GAP-C104, scQC's silent
   acceptance of single cells that another tool denoised becomes an asked, recorded decision (D-031).

### The change
1. **The guard** (`tests/test_portability.py`) reads the lists as conform reads them: `word:`, `exact:`, a trailing `*`
   prefix, whitespace runs, a number never inside a longer number, a bare line as a substring; site shapes from a
   file (`$SCQC_SITE_SHAPES`, `<regex> :: <what> :: <literals>`, a malformed line fails the guard); every file git
   lists, by content, binary files skipped and counted; no self-exemption. The four site shapes it spells today move
   out to the site's file (the generated SAMBO shapes carry the same four by name). A new test,
   `tests/test_leak_guard_reads_the_generated_syntax.py`, copies the guard into a temporary tree and fails on the base
   guard because it reads the syntax as literal text and reads no shapes file.
2. **Every hit goes, file by file, its fact restated without the cohort**; a cohort's measured number goes even where no
   list holds it (ATTACKS 16: the comments, docstrings and docs are read for counts, sizes and times), test inputs
   become synthetic values with their expected results recomputed, the factor levels become neutral levels. No scope
   list, no excuse. In files a promoted job executes only comments, docstrings and message text change; no computed
   value. The fixture's run products (reports, tables, STATUS) are scanned too (ATTACKS 5).
3. **The fixture's axes**: `fixture-run` is TOLD the assay (`--assay`, required, no default) and the design's factor
   (`--design-factors`, passed to `scqc run`), and after the run reads the run's own records and fails, naming the axis,
   when one did not reach its step: the assay in the run's inputs and report, the declared factor in the run's design
   record, the told mitochondrial prefix and ribosomal pattern matching genes of the object AND giving a non-zero
   fraction in every library's per-cell table. DEVPOINTS passes `--assay scrna` (the suite's object holds cells) and
   `--design-factors {role_condition}`. Shown red with one axis broken on a scratch copy, base and head.
4. Suite with a decoy `tests` package on PYTHONPATH that raises on import; docs made true; if executed files changed,
   dated re-pinned copies of W043's two reproduction jobs (prediction unchanged), not submitted.
