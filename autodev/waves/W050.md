# W050 (ANNO): `embed` names a library from the object or the manifest, never from a file name

**Registered** 2026-11-11 by the coordinator, before any code. ROUTE item R47 (added by the route's sufficiency check).
**Gaps** GAP-C103. **Goals** A1.1, A3.1, ANNO.1. **Repository** github.com/JiaenLin/scAnno, branch
`autodev/W050-library-name`, from `main` (`9fb561c`). It does not stack on W044's held tree branch: the files are apart.

## Why
When `--sample-key` is absent from the per-library objects, `embed` fills the joint object's library column with each
file's stem. Through the harness the per-library files carry a stage suffix in their names, so the joint object's
library column reads the name plus that suffix, and a later stage keyed on the cohort's library column finds no library
(read from the code by the driver's fix-round builder; scIntegrate's half of the same break is W046). A chained run of a
cohort whose library column is not the first tool's own word therefore stops at stage 4.

## The change
1. `embed` takes each library's name from what the object itself records (a column that is constant within the file, or
   the name the upstream stage recorded in the object) or from the manifest it is given, in a stated order. It never
   derives a name from a file's name.
2. When it cannot tell (no record, or two candidates that disagree), it refuses by name and says what to pass
   (ATTACKS 18: no silent pick). A name that the output format forbids is refused before anything is computed
   (ATTACKS 25).
3. The joint object records where each library's name came from.

## Acceptance check
- A test that fails at `main` for the stated reason: per-library files whose names carry a suffix give a joint object
  whose library column holds the libraries' own names; two disagreeing candidates are refused by name.
- The suite green with a shadowing `tests` package present; the untruncated leak scan 0 for each cohort; the fixture
  check passes; no assay rule touched.
- If `embed` is on a promoted run's path: a dated, re-pinned copy of that run's reproduction job, predicting the
  promoted labels IDENTICAL and the library column unchanged where the key was present.

## Prediction
No scored test moves by itself. It removes one of the two tool-side breaks that stop a chained stage 4 (A1.1's last
stages for the second cohort, and A3.1 with them).
