# W054 (PLAT): Lab's run section as a closed reader, and one file per conversion

**Registered** 2026-11-12 by the coordinator, before any code. It builds the recommendation of the root design review
[`audits/ROOT_DESIGN_W017_run_section.md`](../audits/ROOT_DESIGN_W017_run_section.md) (RULES item 20; the PI,
2026-11-12: "when the fine tune did not work for many times, use fable to check root design"). **Gaps** GAP-C119,
GAP-C125. **Goals** PLAT.2, A6.2. **Repository** scrnaseq-lab, branch `autodev/W054-run-closed-reader`, from `main`
(`ca0cc73`, live). Its deploy follows its verification without a question (D-045).

## Why
Five fix-ups of the run section failed verification, and the review found the cause in the design: the section was
specified by where to look and a promise to copy whatever is there, never by what a run record is, so its input became
all of HDF5, while its only reader, Studio's Run card, shows six short strings. Live today: a link out of the input file
is followed, by every lookup of the converter and not only this section; a record's host paths travel into a bundle a
user shares.

## The change (the review's steps 1 to 3)
1. **One file.** The converter opens only its input, in the command and in the worker; a link that leaves the file is
   named once and never followed, for every part of the object (the observations, the matrix, the layers, the
   embeddings, the run section).
2. **A closed reader.** Discovery of run records stays, capped at 64. From each record the converter reads six named
   scalar strings (`tool`, `version`, `commit`, `stage`, `run_key`, `job`), each of 256 characters or fewer, and nothing
   else: no walk, no depth, no budgets, no identity of objects; the bundle's keys are the converter's own literals.
   Everything else in a record is named as not carried.
3. **The claim narrowed**, in the review's words: the lab carries the run's identity, not the run's record. The walk's
   tests and fixtures are retired; the committed fixture's digest changes and is predicted before the change.
4. **Not in this wave:** Studio's Run card copy (its own small step); the harness writing one run record per stage into
   the object (GAP-P20, the only source of `stage` and `run_key` for A6.2).

## Acceptance check
- The last re-checker's three reproductions end by construction: a link out of the file is never read (the same input
  bytes give the same bundle whatever sits beside the input); two files of one name cannot collide; a field named like
  an object property cannot vanish, because no field name comes from the input.
- No host path, argument list or input path of a tool's record is in a bundle.
- The crossed-design fix and the embeddings rule of W017 are untouched: each cell keeps its condition; a latent space is
  never cut to two dimensions.
- The deployed Studio opens the new fixture's bundle and shows the six fields, as recorded.
- Lab's suite, lint and build green; two conversions byte-identical.

## Prediction
A6.2 does not move by this wave (its second half needs GAP-P20). Three live defects close, and a bundle stops carrying
a site's paths.

## Fix round 1 (2026-11-12): plan, before any code
The verifier found the run section sound and failed the wave on R1 and R2; this round fixes those and S1 to S3, on
`autodev/W054-run-closed-reader` from `8b4997e`.

- **R1, one read.** h5wasm reads every dataset's and attribute's values through one call into HDF5 and drops its
  status. `openInput` now wraps that call on the module, beside the seal: a read HDF5 reports as failed throws a named
  error, and its buffer is never handed on as values (after a failed variable-length read the buffer is not freed as
  strings either). The rule per use, in the README: an optional part (an embedding, a matrix not chosen, an annotation
  column, the var's other names, raw's genes) is named in a note and absent; a part the bundle depends on (the gene
  names, the obs table in the legacy layout, the chosen matrix at its load, every matrix when none is readable, an
  obs column a role names, or one named like the role being guessed) stops the conversion and names the dataset.
  Stored types are checked before a read: a matrix part, an embedding or a column's codes that is not numbers
  (opaque, compound, strings, an empty dataspace, half-precision floats) is named and left out, never reinterpreted.
  Embeddings are read during the scan, so one HDF5 cannot read is never offered.
- **R2.** Every record found and not listed (none of the six, not a dict, unreadable, past the cap, after a long
  value) is counted in `run.leftOut`, in uns order, the first ten named.
- **S1.** A link is named by its own place in the file and said to point outside it; no target text is carried
  (external links, soft links to nothing, a virtual dataset's source files).
- **S2.** A name from the input that a note or the run section's lists carry is cut at 200 characters, marked.
- **S3.** A record cut by a long value names, in its note, the fields it holds that were not read.
