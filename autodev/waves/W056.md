## Why
The stage driver's batch (W041 + W042 + W049) is VERIFIED at `110417c` (its lean re-check: PASS with limits). Three
things stand between it and `main`, and none of them is a defect of the driver:
1. it was built from an older `main`; W052's branch touches two of its files (the kernel's report, and the stand-in of
   scIntegrate), so the merge is by hand;
2. W045 (one published object becomes per-library parts, `4fb23df`, 899 tests) was built on the driver BEFORE its three
   fix rounds, and has never been verified;
3. the driver has never run a cohort. The first cohort's chained request is a draft with three unknowns
   (`stages/00_driver/request.draft.yml` in that cohort's project), so no job was generated and no gate exists.

## The change
1. **The merge.** `autodev/W049-fix1` (`110417c`) merged into this branch by hand. Each conflict hunk is listed in this
   file with the lines kept from each side and why. No behaviour of either side changes: every test either parent added
   is present and passes at the merged head (the test ids of each parent are a subset of the merged head's, or each
   missing id is named with its reason).
2. **W045 brought on.** `autodev/W045-object-intake` (`4fb23df`) merged the same way. Where it relied on driver
   behaviour the fix rounds changed (a sealed stage's answer, the run's record against each seal, a job stating each
   tool's commit), it follows the fixed driver, said line by line.
3. **The first cohort's chained request, finished.** Each unknown is a cohort fact or a design the cohort's names
   declare: looked up in the cohort's own records, measured where it can be measured, decided and labelled where the
   records leave a choice (PRE_DECIDER step 4), never asked and never invented. What stays unknown is a limit written in
   the request's own header. The one that is a design and not a lookup: which of stage 2's columns become the label
   columns stage 3 reads, when stage 3 is fed by the chain and not by the promoted joint object.
4. **The job, generated and not hand-written:** by the driver's own generator, `--tool` naming each of the four tools
   at a full commit (each tool's `main` on the day; scIntegrate at `2fc7a6c`). A subset job first (the chain is far over
   two hours), drawn so that every stage can run on it: withheld cells present, and a design stage 4 can estimate.

   that would fail it.** Where the chain feeds a stage an input no recorded run had, the prediction says so and
   predicts what can be known beforehand (cells in and out, columns, state versions, the seals, the agreement of the
   chain's labels with the promoted labels within a band stated now). No value is fitted after the run.
