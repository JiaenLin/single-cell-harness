# W060 (ALL): docs-truth sweeps, one repository a run, by Fable reviewers

**Registered** 2026-11-12 by the coordinator. ROUTE item R39, moved up by the direction review of 2026-11-12 (the
cheapest points under a bar: no Opus slot, no cluster). **Goal** A2.2 (1 of 8 today: only the service's repository had
no false claim at audit pass 0004). **Repositories, in this order:** scQC, scAnno, Lab, the Studio (after W057 is
live), then scIntegrate, scProfile and the harness when their route items settle. The service is never touched.

## Why
GOALS A2.2: each repository's README and docs state inputs, outputs, how to run and how to reproduce; an auditor
samples at least 10 claims per repository against the code, and none is false. Pass 0004 drew 12 claims a repository
and re-checked 18 known-false lines: 9 new false claims in 5 repositories and 17 known-false still false. Since then
every tool has merged waves that changed behaviour; each builder corrected the docs its own change touched, and no one
has read a repository's docs whole.

## THE CLASS
Every sentence in a repository's README, docs and bundled guides that states something a reader can check against the
code at `main`: an input or an output and its name, a command and its flags, a default, a number, a file the tool
writes, a step of how to reproduce, a cited source. The ONE place that defines the set: the list of documentation
files the repository ships (found by reading the tree, written in the sweep's note). The ONE test that walks it: a
seeded draw of 12 claims by ANOTHER agent after the sweep, each checked against the code (and a cited source resolved,
one cited claim a document read against it: RULES item 18). Outside, counted: help text and messages inside the code
(a false one is listed for that repository's next builder, never edited here); developer notes that state history.

## THE SIZE (one repository a run; two agents)
1. THE SWEEP (a Fable reviewer; docs only, on a branch `autodev/docs-truth-<n>` from `main`): every claim of the class
   read against the code; pass 0004's known-false lines for that repository first; each false or stale line corrected
   to what the code does (the code is never changed to match a doc); a note of every claim checked and every line
   changed, with the code line that decides it.
2. THE DRAW (another Fable agent, after the sweep is pushed): Random(seed stated before the draw), 12 claims over the
   repository's documentation files at the branch head, each TRUE, IMPRECISE or FALSE with its evidence; the row for
   A2.2 is written from it. None false: the branch merges (docs only: no gate job; the executed files are unchanged)
   and the repository counts. Any false: the sweeper's residue, one more run, then the repository waits.

## Acceptance check
- The branch's diff touches documentation files only (a diff of the files a job executes against `main` is empty).
- The draw's 12 claims: none FALSE. The known-false lines of pass 0004 for the repository: each corrected or shown true.
- The repository's own suite and leak guard still pass (docs can be guarded: a test that reads a README must stay green).

## Prediction
A2.2 +0.125 for each repository whose draw has no false claim; four repositories reach the bar of 0.5.
